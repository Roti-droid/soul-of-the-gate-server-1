# «Войти через Google» — как включить (один раз, ~15 минут)

Пока это не сделано, кнопок Google в игре просто нет, всё остальное работает как раньше.
Вход идёт через **обычный браузер телефона** (внутри игры Google вход запрещает): игра открывает браузер,
игрок выбирает свой Google-аккаунт, видит «Готово — вернитесь в игру», возвращается — и игра сама всё подхватывает.

Адрес сервера (проверено в коде): `https://crystal-run-server.ken729710.workers.dev`

---

## 1. Проект в Google Cloud

1. Откройте https://console.cloud.google.com/ и войдите своим Google-аккаунтом.
2. Сверху слева нажмите выбор проекта → **New project (Новый проект)**.
3. Название: `Soul of the Gate` → **Create**. Дождитесь, пока проект создастся, и выберите его сверху.

## 2. Экран согласия (OAuth consent screen)

В меню слева: **APIs & Services → OAuth consent screen**
(в новой версии консоли это называется **Google Auth Platform** → кнопка **Get started**).

1. **App name (Название приложения):** `Soul of the Gate`
2. **User support email:** ваша почта.
3. **Audience / User type:** **External (Внешние)**.
4. **Contact email:** ваша почта → согласиться с правилами → **Create / Save**.
5. **Scopes (Доступы)** — добавьте только три: `openid`, `.../auth/userinfo.email`, `.../auth/userinfo.profile`
   (они «несекретные», проверка Google для них не нужна).
6. **Кто может входить:**
   - пока приложение в режиме **Testing** — входить могут только люди из списка **Test users** (добавьте туда свои
     почты и почты тестеров, до 100 штук);
   - чтобы входить мог **любой игрок** — в разделе **Audience** нажмите **Publish app → Confirm**
     (статус станет «In production»).

## 3. Ключ входа (OAuth client ID)

В меню слева: **APIs & Services → Credentials** (или **Google Auth Platform → Clients**).

1. **Create credentials → OAuth client ID**.
2. **Application type:** **Web application** (именно «Веб-приложение», не Android).
3. **Name:** `Soul of the Gate server`.
4. **Authorized redirect URIs → Add URI** — вставьте ровно так, без пробелов и без `/` в конце:

   ```
   https://crystal-run-server.ken729710.workers.dev/auth/google/callback
   ```

   («Authorized JavaScript origins» заполнять не нужно.)
5. **Create**. Появится окно с двумя значениями — **Client ID** (заканчивается на `.apps.googleusercontent.com`)
   и **Client secret**. Скопируйте их (окно можно открыть снова в списке Clients).

> Client secret — это пароль. Никому не присылайте, не вставляйте в игру, в чат и в файлы проекта.
> Он хранится только в Cloudflare как секрет (шаг 4).

## 4. Отдать ключи серверу

Откройте командную строку в папке `webrelease-donate` (там, где лежит `deploy.bat`) и выполните по очереди:

```
npx wrangler secret put GOOGLE_CLIENT_ID
```

Когда спросит значение — вставьте **Client ID** и нажмите Enter.

```
npx wrangler secret put GOOGLE_CLIENT_SECRET
```

Вставьте **Client secret** и нажмите Enter. (Символы при вставке могут не показываться — это нормально.)

## 5. Залить сервер

Запустите **deploy.bat** (двойной клик). Дождитесь «ГОТОВО!».

## 6. Проверка

1. Откройте https://crystal-run-server.ken729710.workers.dev/auth/google/start?s=AAAAAAAAAAAAAAAAAAAAAAAA
   — должна открыться страница «Не получилось · Вход через Google устарел». Это правильно: значит, Google настроен.
   Если там написано «Google-вход не настроен» — секреты из шага 4 не сохранились, повторите шаг 4 и 5.
2. В игре: **Профиль → Достижения и аккаунт** → появились кнопки **«Привязать Google»** и **«Войти через Google»**.
3. Нажмите «Привязать Google» → откроется браузер → выберите аккаунт → страница
   «Привязать Google-аккаунт i***@gmail.com к игровому аккаунту «ник» (ID ****1234)?» → **«Привязать»** →
   «Готово!» → вернитесь в игру. (Пока страница открыта, игра пишет «Подтверди привязку в браузере».)
   На кнопке будет «Google привязан · i***@gmail.com».
4. На другом телефоне (или после переустановки): Профиль → **«Войти через Google»** → тот же аккаунт →
   вернитесь в игру — загрузится ваш прогресс.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| Google пишет **redirect_uri_mismatch** | В шаге 3.4 адрес вставлен не точь-в-точь. Исправьте и подождите 5 минут. |
| Google пишет **access_denied / app not verified / доступ заблокирован** | Приложение в режиме Testing, а почты нет в Test users. Добавьте её или нажмите Publish app (шаг 2.6). |
| «Этот Google-аккаунт уже привязан к другому игровому аккаунту» | Этот Google уже привязан к другому аккаунту игры. Нажмите «Войти через Google», чтобы открыть тот аккаунт. |
| «К этому Google-аккаунту не привязан игровой аккаунт» | Сначала на старом телефоне: Профиль → «Привязать Google». |
| «Вход через Google устарел» | Ссылка живёт 10 минут и срабатывает один раз. Нажмите кнопку в игре ещё раз. |
| «Подтверждение привязки устарело» | Страницу «Привязать Google?» нужно подтвердить за 5 минут. Нажмите кнопку в игре ещё раз. |
| «Привязка отменена» | На странице нажали «Отмена» — ничего не привязано. |

Отвязку Google пока не делали — если нужно, напишите.

### Для разработчика (кратко)

- Сервер: `google.js` (страницы `/auth/google/start` и `/auth/google/callback`, PKCE S256, обмен кода на
  `oauth2.googleapis.com/token`, проверка id_token: iss, aud = GOOGLE_CLIENT_ID, exp), `accounts.js`
  (таблица `gstates`, колонки `google_sub` UNIQUE и `google_email` — хранится только маска `i***@gmail.com`),
  `index.js` (команды сокета `google_start{mode}` → `google{url,p}`, `google_poll{p}` → `google_wait` |
  `google_done` + `acc`).
- **Защита от подмены привязки (link-CSRF).** Чужую ссылку «Привязать Google» можно подсунуть жертве — тогда её Google
  привязался бы к чужому игровому аккаунту. Поэтому в режиме link callback после проверки id_token **ничего не
  привязывает**: verified `sub` + маска почты ждут в `gstates` (phase 3, `GOOGLE_CONFIRM_TTL_SEC`, по умолчанию 300 с),
  браузер видит страницу «Привязать …? Если ты не нажимал(а) «Привязать Google» в игре только что — нажми «Отмена»».
  Привязывает только `POST /auth/google/confirm` (форма: `state` + одноразовый `csrf`, в БД лежит только его SHA-256;
  `Origin` обязан быть этим воркером, пустой/`null`/чужой → 403; страница с `Referrer-Policy: same-origin`, CSP
  `frame-ancestors 'none'; form-action 'self'`). `POST /auth/google/cancel` → «Привязка отменена». Повтор, просрочка,
  новый `google_start` того же аккаунта → «устарел». Режим login не менялся (он входит только в уже привязанный аккаунт).
- Пока страница подтверждения открыта, `google_poll` отвечает `{t:"google_wait", stage:"confirm"}`
  (без подтверждения — просто `{t:"google_wait"}`); после «Отмена» — `{t:"error", re:"google_poll", msg:"Привязка отменена"}`.
- Без секретов `acc` не содержит `google_on`, игра прячет кнопки; `/auth/google/*` отвечает 503 «Google-вход не настроен».
- Тесты: `bash test/run_tests.sh` (поднимает третий wrangler dev на :8795 с фейковыми ключами и подменённым
  token endpoint на :8797 — `test/test_google.py`).
