# 2.2 «Онлайн и сезоны» — серверная часть

## Что добавлено
- **online.js** — новый Durable Object `Online` (SQLite, бесплатный план). HTTP API `/api/v2/*` (подключён в `index.js`, привязка и миграция `v4` — в `wrangler.toml`). Старые функции (комнаты, донат, аккаунты) не менялись.
  - **Испытание дня**: `GET /api/v2/daily` выдаёт сид, сложность, модификаторы и цель. Всё считается из даты UTC тем же `mulberry`, что в игре, поэтому офлайн клиент получит тот же сид. Отправка результата: `POST /daily/submit`. Таблица дня: `GET /daily/top`.
  - **Призраки**: компактная запись (≈3 байта на каждые 0,2 с) хранится вместе с рекордом дня. Забрать: `GET /ghost`.
  - **Профиль**: аватар, скин, статистика, уровень/XP. XP начисляет только сервер.
  - **Рейд-босс недели**: общий запас HP. Сброс каждый понедельник 00:00 UTC (автоматически, по номеру недели). 4 босса по кругу, HP растёт с каждым кругом. Награды по нанесённому урону.
  - **Сезон**: 30 уровней вместо 12. Уровни дороже (2650 м за первый, дальше каждый на 150 м дороже, всего ≈140 км). Награды больше: до 3000 кристаллов за уровень и 6 скинов.
  - **Входящие (inbox)**: все награды и подарки приходят сюда, клиент забирает их и подтверждает (`/inbox`, `/inbox/ack`).
  - **Онлайн сейчас**: `POST /ping`, `GET /online`.
  - **God-панель** `POST /api/v2/god`: выдать кристаллы или скин, бан/разбан, кто онлайн, карточка игрока, задать сезон, сбросить рейд, журнал. Права проверяются **только на сервере**: ID аккаунта владельца + ключ. Каждое действие и каждая неудачная попытка пишутся в журнал (сам ключ в журнал не попадает). Неверный ключ можно ввести не больше 5 раз за 10 минут с одного IP.
  - **Защита**: лимит запросов с одного IP, паузы между отправками для каждого аккаунта. Проверка правдоподобия: средняя скорость не выше максимальной для сложности ×1,25. Время забега от 1 с до 90 мин. Число кристаллов проверяется. Призрак сверяется по шагам и общей дистанции. Подозрительные результаты отклоняются и попадают в журнал (`cheat:*`), у игрока растёт счётчик `flags`. Забаненные не видны в таблицах.
- **realtime_draft.js** — ⚠️ **НЕ ГОТОВО.** Только заготовка и описание для «Королевской битвы шаров» и «Эстафеты 2×2». Файл не подключён и не заливается.
- **test/test_online.mjs** — 40 проверок, локально все проходят.
- Клиент (черновик, в игру ещё не встроен): `game3d/tmp/online/online_api.js`. В нём обёртки над запросами, работа офлайн (кэш и очередь отправки), тексты RU/EN через ключи, запись и чтение призраков.

## Секреты (один раз)
```
npx wrangler secret put OWNER_ID
npx wrangler secret put GOD_KEY
```
- `OWNER_ID` — ID твоего игрового аккаунта (12 символов). Его видно в консоли игры: `SAVE.acc.id`.
- `GOD_KEY` — длинный случайный пароль (от 24 символов). Придумай сам и **никуда не записывай в игру**: в god-панели его вводят руками.
- Без этих двух секретов god-панель просто отвечает «нет доступа», остальное работает.

## Как залить
Как обычно: `deploy.bat` (или `npx wrangler deploy`). Миграция `v4` создаст новую базу сама, старые данные не трогаются.
Проверка после заливки: открыть `https://crystal-run-server.ken729710.workers.dev/api/v2/daily` — должен прийти JSON с `seed`.
