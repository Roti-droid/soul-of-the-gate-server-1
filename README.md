# «Кристальный забег»: игра по ссылке и онлайн-сервер

1. Распакуй архив в любую папку и дважды кликни **deploy.bat**. Нужен установленный Node.js. Если откроется браузер, нажми **Allow**.
2. Когда появится «ГОТОВО», игра будет открываться по ссылке **https://crystal-run-server.ken729710.workers.dev/**, и её можно присылать друзьям. Онлайн-режим работает через тот же адрес, старые APK тоже продолжат работать.
   Проверка сервера: https://crystal-run-server.ken729710.workers.dev/health (должна показать `Crystal Run server OK`).

## Как сделать Telegram Mini App

1. В Telegram открой **@BotFather** и отправь `/mybots`.
2. Выбери своего бота, затем **Bot Settings → Menu Button**. Пришли ссылку `https://crystal-run-server.ken729710.workers.dev/` и название кнопки, например `Играть`.
3. Можно сделать и отдельное мини-приложение: отправь `/newapp`, выбери бота, введи название, описание и картинку 640×360, вместо GIF пришли `/empty`. Потом пришли ту же ссылку и короткое имя (например `play`). Ссылка на игру будет `https://t.me/<бот>/play`.

## Донат звёздами Telegram (один раз)

1. Сначала запусти **deploy.bat**, как обычно.
2. В Telegram открой **@BotFather**, отправь `/newbot`, придумай имя и username, который заканчивается на `bot`. BotFather пришлёт **токен**. Включать Payments **не нужно**: звёзды работают и так.
3. Дважды кликни **setup_bot.bat**. Он спросит:
   - токен бота;
   - твой Telegram id (число): его можно узнать у @userinfobot;
   - ник для вопросов о возврате (можно оставить пустым).

   Дальше он всё сделает сам: сохранит секреты в Cloudflare, зальёт сервер и подключит бота.
4. Напиши боту `/start` — должно появиться меню с наборами. Кнопка **«Поддержать»** в игре сама откроет этого бота.

Как это работает: игрок платит звёздами ⭐ в боте, бот присылает код `CR-XXXX-XXXX`, а игрок вводит его в игре в разделе **Магазин → Поддержать → Ввести код**. Каждый код срабатывает только один раз.

Команды админа в боте:
- `/stats` — статистика;
- `/gift 1000 royal` — подарочный код;
- `/refund CR-XXXX-XXXX` — вернуть звёзды;
- `/revoke CR-XXXX-XXXX` — отозвать код;
- `/admin` — список всех команд.

Важно:
- Используй **отдельного** бота для доната. Если этот бот уже где-то работает (например на другом хостинге), setup_bot.bat переключит его на Cloudflare.
- Если поменяешь токен, просто запусти setup_bot.bat ещё раз.
- **Возраст:** принимать звёзды можно сразу. А вот чтобы **вывести** звёзды в деньги (через Fragment), Telegram может попросить подтвердить возраст и личность. Для вывода может понадобиться взрослый.

## Аккаунты, облачные сохранения и рекорды (версия 1.8)

Это работает само после **deploy.bat**, больше ничего настраивать не нужно.
- Игрок получает аккаунт, может выбрать ник, а прогресс сохраняется на сервере.
- Аккаунт можно привязать к Telegram через бота.
- На новом устройстве: отправь боту `/login` и введи присланный код `G-XXXXXX` в игре.
- Сезоны длятся по 14 дней, для каждой сложности своя таблица рекордов.

Всё бесплатно, на тарифе Cloudflare Free. Папку `node_modules` deploy.bat создаст сам.
